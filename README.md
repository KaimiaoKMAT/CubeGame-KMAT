# CubeGame-KMAT
CubeGame(A 3D cube game for HP Prime)

English:
CubeGame
 
(The opening content corresponds to Version 1.0 by default; subsequent update notes will be marked accordingly)
 
Camera rotation (and menu selection): Up, Down, Left, Right
Movement: 8 = Move forward, 4 = Move left, 6 = Move right, 5 = Move backward
Adjust values in menus: +, -
Place block: Apps
Break block: HOME
Quit: ESC
Open menu: Menu
 
Jump: Spacebar
 
It may look somewhat similar to Minecraft. However, Version 1.0 did not implement Y‑axis related features (in this 3D rendering, Z represents depth).
Jump functionality has now been added.
 
KMAT 2026
@Kaimiao / kaimiao
 
3D rendering powered by custom‑built KM3D, with additional extended features outside KM3D.
 
v1.0 Release date: 2026‑07‑30
 
v1.1 Update (2026‑09‑12):
 
1. Removed adjacent duplicate faces during rendering
2. Added more configurable options to the settings menu
3. Mitigated game speed anomalies caused by game lag
4. Reduced floating‑point errors when running on G1 physical hardware
5. Implemented jump mechanic and Y‑axis collision detection
6. Added an optional, extremely aggressive culling mode
